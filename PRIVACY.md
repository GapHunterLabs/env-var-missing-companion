# Privacy Policy — Env Var Missing Companion

**Effective date:** 2026-08-19

Env Var Missing Companion is a Gap Hunter Labs plugin for IntelliJ
Platform IDEs. This policy is short because the plugin's design makes
it short: there is nothing to disclose beyond what's below.

## What this plugin collects

**Nothing.** Env Var Missing Companion does not collect, store,
transmit, or sell any data — no source code, no file contents, no file
paths, no environment variable names or values, no usage analytics, no
telemetry, no crash reports, no personally identifiable information.
Your open file's text and your project's `.env`/`.env.example`/etc.
files exist only in memory for as long as the IDE is open, and only
long enough to compute each variable's declared/undeclared verdict.

## Network access

**None.** Env Var Missing Companion makes zero network calls during
normal operation. Every warning shown is computed directly from files
already present on your local disk — no external service, no
telemetry endpoint, ever.

## Third parties

None. Env Var Missing Companion has no third-party SDKs, no analytics
libraries, no ad networks, no external dependencies that phone home.

## Changes to this policy

If this ever changes, this file will be updated and the change will be
noted in the plugin's `CHANGELOG.md`.
