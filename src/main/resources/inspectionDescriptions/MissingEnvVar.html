Reports an environment variable read in code (process.env.PORT, process.env["PORT"], os.environ["DEBUG"], os.environ.get("DEBUG"), os.getenv("TIMEOUT")) that is not declared in any of the project's .env or .env.example files.

An undeclared variable is usually missing in some environment, where the code then runs with an empty value. The quick fix adds the variable to the .env file. JavaScript, TypeScript and Python files are checked, one open file at a time.
